JSON連携の制限事項

JSONデータソース

  • テーブル名、データソース名、カラム名を修正しても、データソースの自動変更は行われません。

  • 定義されたJSONのデータソースに対する複写登録、上書登録、移動登録は無効です。

  • 複数の異なるデータソースで、同じデータソース名を定義した場合、正しく動作しません。構文チェック（F8）でエラーは出力されません。

  • データソースのテーブル定義を削除しても、対応するJSONファイルは削除されません。

  • プライベートデータソースを設定したJSON型のカラムの名前を変更したい場合、そのカラムを削除して再定義する必要があります。

  • 共有データソースを設定したJSON型のカラムは、それに対応するテーブル名と同じ名前に設定する必要があります。

  • 配列のないJSONファイルは、JSON DBに対応していません。

プログラム

  • プログラムでJSONデータソースに書き込まれたデータについて、改行やインデントの整形は行われません。

  • JSON型項目は、フォーム上で直接［エディット］コントロールに設定できません。

  • RIAプログラムでは、JSON型に対応するデータソースをメインソースとする子タスク(子プログラム)は、サブフォームに対応していません。
