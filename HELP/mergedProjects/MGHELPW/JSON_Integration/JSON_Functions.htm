JSON 関数

JSON関数を使用することで、JSONドキュメントを操作することができます。

JSONCnt

JSONオブジェクト/配列の出現回数を、JSONソース変数 をそのパスにしたがって取得します。

JSONDelete

JSONオブジェクト/配列をJSONソース項目から削除します。

JSONExist

JSONオブジェクト/配列がJSONソース項目に存在するかどうかをチェックします。

JSONFind

JSONソース項目からJSONオブジェクト/配列を検索します。

JSONGet

JSONオブジェクト/配列の値を、JSONソース項目から、その値に応じて返します。

JSONInsert

JSONオブジェクトをJSONソースに挿入します。

JSONModify

JSONオブジェクトの値を変更します。

 

JSON関数の第1パラメータについて

JSON関数の第1パラメータであるJSONソースは、通常プログラム内で定義した変数のJSON型項目を設定します。

この項目の内部の文字コードはUnicodeですが、［項目更新］処理コマンド、あるいはFile2Blb関数でJSONファイルからデータを設定する場合は、文字コードに関する変換関数を使う必要はありません。

JSON型項目をファイルに出力する場合、通常はBlb2Fle関数を使用しますが、第2パラメータのファイル名の拡張子によって以下のように動作が変わります。

  • .json を指定した場合、UTF-8に自動変換されます。

  • .json以外を設定した場合には、UTF-16LEで出力されます。
