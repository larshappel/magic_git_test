JSONの利用方法

JSONを扱うには、2つの方法があります。

  • JSONデータソースの利用

  • JSON関数の使用

JSONデータソースの利用

  1. ［データベース］テーブルで［データソースタイプ］に「J=JSON」を指定したエントリを作成します。［位置］にJSONファイルを格納するフォルダを指定することができます。

  2. ［データ］リポジトリ で［データベース］にこのエントリを指定したテーブルを作成します。

  • テーブルの名前: JSONの最初のkey(変数)の名前

  • データソース名：JSONのファイル名

  • カラムの名前: 配列[...]で囲まれたkey(変数)の名前

  • インデックス: JSONの定義には影響しません。

  1. プログラムでは、メインソースまたは、リンクテーブルに定義してデータを操作します。
