Web Clientアプリケーション

Magic xpaは、Web Clientアプリケーションに対する総合的なソリューションを提供します。

Web Clientは、リモートおよび分散ユーザにサービスを提供するビジネスアプリケーションを開発および実行するためのプラットフォームです。

インストール要件

Web Clientアプリケーションをクライアントにインストールするには、以下の前提条件が必要です。

  • Node-js® …… ChromeのV8 JavaScriptエンジンでビルドされたJavaScriptの実行環境。最小推奨バージョン：12.22.9。

  •  Windows 32bit …… https://nodejs.org/download/release/v16.16.0/win-x86/

  • Windows 64bit …… https://nodejs.org/download/release/v16.16.0/win-x64/

  • NPM …… JavaScriptランタイム環境Node-jsのデフォルトのパッケージマネージャ。Node-jsをインストールすると インストールされます。このため、NPMを別途インストールする必要はありません。裁定推奨バージョン：8.3.0。

  • Angular/CLI …… プロジェクトの作成、ファイルの追加、テスト、ビルド、デプロイなどのさまざまな開発作業を実行できるコマンドラインインターフェイス。最小推奨バージョン：13.0.0。
    Node-js をインストールした後、以下のコマンドを実行してインストールします。

npm install -g @angular/cli@13

 

npm config set legacy-peer-deps true

 

インストールされたAngularのバージョンを確認するには、以下のコマンドを実行してください。

ng version

  • HTML コードエディタ …… 開発作業をサポートするNotepad ++、WebStorm、Visual Studio Codeが使用できます。Visual Studio Codeは、https://code.visualstudio.com/Download からダウンロードできます。推奨バージョン：1.64.0。
