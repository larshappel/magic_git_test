JSONModify

JSONオブジェクトの修正

JSONオブジェクトの値を変更できるようにします。

構文：

JSONModify (JSON ソース, オブジェクト・パス, 値)

パラメータ：

  • JSON ソース …… JSON 型項目の参照値です。

  • オブジェクトパス  …… パスの中の1つのオブジェクトを一意に定義する文字列です。

  • 値 …… オブジェクトを変更したいデータを含む値です。

戻り値：

数値 …… 実行に成功した場合は0、それ以外の場合は以下のような負の数が返ります。

  • -1 …… パスが見つかりません。

  • -2 …… JSONソース項目にキーが存在しません。

  • -4 …… パスで使用されているインデックスが無効です。

  • -5 …… JSONの解析中にエラーが発生しました。

  • -6 …… パラメータが指定されていません。

  • -7 …… 指定されたソース項目がJSON型ではありません。

  • -8 …… 指定されたソース項目がNULL です。

  • -9 …… オブジェクトのパスがインデックスを持たない配列を参照しています。

  • -12 …… インデックスまたは[]が単一のインスタンス（オブジェクト）で使用されています。

例：

JSONModify ('A'VAR, '/AddressBook[1]/Contact[1]/Name','John Smith')

 

'A'VAR は、JSON型のデータ項目です。以下の JSONデータが含まれています。

 

オブジェクトパス '/AddressBook[1]/Contact[1]/Name' を使用して、与えられたJSONファイルから、値 'John Smith' を使用して Nameを修正することができます。

ここでは、"Mrs Lee Smith "という文字列が "John Smith "に変更されます。

 

{"AddressBook": [{
            "Contact": [{
                           "Record_ID": 0,
                           "Name": "Mrs. Lee Smith"
                      },
                      {
                           "Record_ID": 1,
                           "Name": "Mr. Joy Smith"
                      }  ]
            }  ]
}

 

配列の修正

 

JSONModify('A'VAR,'/AddressBook[1]/Contact[1]',

    '{"Address":[{"HouseNum":40},

     {"StreetName":"BakerStreet",

      "Landmark":"Near Fountain"

    },

    {

      "PIN":"EA-0080",

      "Contact":"XX.12345678"}]

}')

 

オブジェクトパス '/AddressBook[1]/Contact[1]' とハイライトされた配列要素を使用すると、Contact[] という名前の配列の最初の要素を変更することができます。

結果は、以下のようになります。

 

{ "AddressBook": [{

      "Contact": [{

           "Address": [{

              "HouseNum": 40

            },
          {
              "Landmark": "Near Fountain",
              "StreetName": "Baker Street"
         },
         {
              "Contact": "XX.12345678",
              "PIN": "EA-0080"
         } ]
   },
   {
      "Name": "Mr. Joy Smith",
      "Record_ID": 1
   } ]
 } ]

 

 

 

JSONModify('A'VAR, '/AddressBook[1]/Contact',

    '{"Address":[{"HouseNum":40},

      {"StreetName":"BakerStreet",

       "Landmark":"Near Fountain"

    },

    {

       "PIN":"EA-0080",

       "Contact":"XX.12345678"

    }]

}')

 

オブジェクトパス '/AddressBook[1]/Contact' を使用して、ハイライトされた配列要素で Contact という名前の配列を変更することができます。

結果は、以下のようになります。

 

{"AddressBook": [{

       "Contact": {

       "Address": [{

             "HouseNum": 40
        },
        {
            "Landmark": "Near Fountain",
            "StreetName": "Baker Street"
        },
        {
            "Contact": "XX.12345678",
            "PIN": "EA-0080"
        } ]
  }  }
] }

 

JSONModify では Contact[] はサポートされていないため、エラー -4 を返します。

 

JSONModify('A'VAR, '/AddressBook[1]/Contact[]',

    '{"Address":[{"HouseNum":40},

      {"StreetName":"BakerStreet",

       "Landmark":"Near Fountain"

     },

     {

       "PIN":"EA-0080",

       "Contact":"XX.12345678"

   }]

}')

注意事項：

オブジェクトのパスとして、複数のインスタンスを指定することはできません。
