JSONCnt

JSONオブジェクト数の取得

JSONオブジェクト/配列の出現回数を、JSONソース変数 をそのパスにしたがって返します。

構文：

JSONCnt (JSON ソース, パス)

パラメータ：

  • JSON ソース …… JSON 型項目の参照値です。

  • パス  …… パスの中の1つのオブジェクト/配列を一意に定義する文字列です。

戻り値：

数値 …… JSONオブジェクト/配列の出現回数。負数の場合は以下のような数が返ります。

  • -1 …… パスが見つかりません。

  • -2 …… JSONソース項目にキーが存在しません。

  • -4 …… パスで使用されているインデックスが無効です。

  • -5 …… JSONの解析でエラーが発生しました。

  • -6 …… パラメータが指定されていません。

  • -7 …… 指定されたソース項目がJSON型ではありません。

  • -8 …… 指定されたソース項目がNULL です。

  • -9 …… オブジェクトのパスがインデックスを持たない配列を参照しています。

  • -10 …… シングルインスタンスのパスは指定できません。

  • -12 …… インデックスまたは[]が単一のインスタンス（オブジェクト）で使用されています。

例：

JSONオブジェクトの出現回数を取得する。

 

JSONCnt('B'VAR,'/AddressBook[1]/Contact')

 

'A'VAR は JSON 型の項目です。以下の JSONデータが含まれています。

パス '/AddressBook[1]/Contact' からJSONオブジェクトの出現回数を取得すると、'Contact'は2つしか存在しないため、"2" が戻り値として返ります。

 

{"AddressBook": [{
           "Contact": [{
                 "Record_ID": 0,
                 "Name": "Mrs. Lee Smith", 
                 "City": "Tel Aviv"
              },
              {
                  "Record_ID": 1,
                  "Name": "Mr. Joy Smith"
           } ]
     }]
}

注意事項：

オブジェクトのパスとして、複数のインスタンスを指定することはできません。
