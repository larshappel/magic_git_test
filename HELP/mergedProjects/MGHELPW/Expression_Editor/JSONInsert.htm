JSONInsert

JSONオブジェクトの挿入

JSONオブジェクトをJSONソースに挿入します。

構文：

JSONInsert (JSON ソース, オブジェクト・パス, キー,値 )

パラメータ：

  • JSON ソース …… JSON 型項目の参照値です。

  • オブジェクトパス  …… パスの中の1つのオブジェクトを一意に定義する文字列です。

  • キー  …… Unicode値。 指定されない場合、パス は配列とみなされ、それ以外の場合はオブジェクトとみなされる。

  • 値 …… オブジェクトを変更したいデータを含む値です。

戻り値：

数値 …… 実行に成功した場合は0、それ以外の場合は以下のような負の数が返ります。

  • -1 …… パスが見つかりません。

  • -3 …… キーがJSONソース項目に既に存在します。

  • -4 …… パスに使用されているインデックスが無効です。

  • -5 …… JSONの解析でエラーが発生しました。

  • -6 …… パラメータが指定されていません。

  • -7 …… 指定されたソース項目が JSON 型ではありません。

  • -8 …… 指定されたソース項目がNULL です。

  • -9 …… オブジェクトのパスがインデックスを持たない配列を参照しています。

  • -10 …… シングルインスタンスのパスは指定できません。

  • -12 …… インデックスまたは[]が単一のインスタンス（オブジェクト）で使用されています。

  • -13 …… 配列またはキーを指すパスのいずれかを挿入することができます。

  • -14 …… 参照する配列が存在しません。

例：

JSONInsert ('A'VAR, '/AddressBook[1]/Contact[1]','City','Tel Aviv')

 

'A'VAR は JSON 型の変数です。以下の JSONデータが含まれています。

 

{"AddressBook": [{
       "Contact": [{
           "Record_ID": 0,
           "Name": "Mrs. Lee Smith"
       },
       {
           "Record_ID": 1,
           "Name": "Mr. Joy Smith"
        } ]
   } ]
}

 

'City' をキー、値 として'Tel Aviv' を指定すると、指定したJSONファイルに "City": "Tel Aviv" を挿入することができます。

 

{ "AddressBook": [{
      "Contact": [{
             "Record_ID": 0,
             "Name": "Mrs. Lee Smith",
          "City": "Tel Aviv"
          },
          {
            "Record_ID": 1,
            "Name": "Mr. Joy Smith"
         } ]
    } ]
}

 

JSON ファイルに配列を挿入

以下の関数を実行すると、JSON ファイルに配列が挿入されます。

 

JSONInsert('A'VAR,'/AddressBook[1]/Contact[1]','Address',
       '[{"HouseNum": 40},
       {"StreetName": "Baker Street",
       "Landmark": "Near Fountain"
   },
   {
       "PIN": "EA-0080",
       "Contact": "XX.12345678"
   }]
')

 

挿入結果は以下のようになります。

 

{ "AddressBook": [  {
   "Contact": [   {
     "Address": [      {
       "HouseNum": 40
      },
      {
       "Landmark": "Near Fountain",
       "StreetName": "Baker Street"
      },
      {
       "Contact": "XX.12345678",
       "PIN": "EA-0080"
      }  ],
     "Name": "Mrs. Lee Smith",
     "Record_ID": 0
    },
    {
     "Name": "Mr. Joy Smith",
     "Record_ID": 1
    }  ]
  } ]
}

 

以下の場合、オブジェクトのパスには、Contact[1]のようなインデックスを持つ配列が含まれていますが、パラメータキーが指定されていません。この場合、エラー-14が発生します。

 

JSONInsert('A'VAR, '/AddressBook[1]/Contact[1]','',

     '{"Address":[{"HouseNum":40},

      {"StreetName":"BakerStreet",

       "Landmark":"NearFountain"},

      {"PIN":"EA-0080",

      "Contact":"XX.12345678"

   }]

}')

 

以下の場合、オブジェクトのパスにContactのような[]のない配列が含まれていますが、パラメータキーとして'Address'という名前が渡されています。この場合、エラー-13が発生します。

 

JSONInsert('A'VAR, '/AddressBook[1]/Contact', 'Address',

      ' [{"HouseNum": 40},

         {"StreetName":"BakerStreet",

          "Landmark": "Near Fountain"

      },

      {

         "PIN": "EA-0080",

         "Contact": "XX.12345678"}]

},')

 

以下の場合、オブジェクトのパスにContactのような[]のない配列が含まれており、パラメータキーが指定されていません。その結果、Contactに新しい配列要素が挿入されます。

 

JSONInsert('A'VAR,'/AddressBook[1]/Contact','',

   '{"Address":[{"HouseNum":40},

    {"StreetName":"BakerStreet",

     "Landmark":"NearFountain"

   },

   {

     "PIN":"EA-0080",

     "Contact":"XX.12345678"}]

}')

 

以下の結果になります。

 

{{ "AddressBook": [{
     "Contact": [{
            "Name": "Mrs. Lee Smith",
            "Record_ID": 0
         },
        {
           "Name": "Mr. Joy Smith",
           "Record_ID": 1
        },
        {
            "Address": [{"HouseNum": 40},
         {"Landmark": "Near Fountain",
        "StreetName": "BakerStreet"

        },
         {

         "Contact": "XX.12345678",

         "PIN": "EA-0080"

       } ]
      } ]
   } ]
}

注意事項：

オブジェクトのパスとして、複数のインスタンスを指定することはできません。
