JSONDelete

JSONオブジェクトの削除

JSONソース項目からJSONオブジェクト/配列を削除します。

構文：

JSONDelete (JSON ソース, パス)

パラメータ：

  • JSON ソース …… JSON 型項目の参照値です。

  • パス  …… パスの中の1つのオブジェクト/配列を一意に定義する文字列です。

戻り値：

数値 …… 実行に成功した場合は0、それ以外の場合は以下のような負の数が返ります。

  • -1 …… パスが見つかりません。

  • -2 …… JSONソース項目にキーが存在しません。

  • -4 ……- パスで使用されているインデックスが無効です。

  • -5 ……- JSONの解析でエラーが発生しました。

  • -6 ……- パラメータが指定されていません。

  • -8 ……- 指定されたJSON項目がNULL です。

  • -9 ……- オブジェクトのパスがインデックスを持たない配列を参照しています。

  • -10 ……- シングルインスタンスのパスは指定できません。

  • -12 …… インデックスまたは[]が単一のインスタンス（オブジェクト）で使用されています。

例：

JSONDelete ('A'VAR, '/AddressBook[1]/Contact[1]/City')

 

'A'VAR は、JSON型のデータ項目です。以下の JSONデータが含まれています。

 

{"AddressBook": [{
       "Contact": [{
             "Record_ID": 0,
             "Name": "Mrs. Lee Smith",
              "City": "Tel Aviv"
       },
       {
           "Record_ID": 1,
           "Name": "Mr. Joy Smith"
        } ]
   } ]
}

 

オブジェクトパス '/AddressBook[1]/Contact[1]/City' を指定すると、指定したJSONの最初のエレメント（Contact[1]）からCityを削除することができます。

 

{"AddressBook": [{
       "Contact": [{
             "Record_ID": 0,
             "Name": "Mrs. Lee Smith",               
       },
       {
           "Record_ID": 1,
           "Name": "Mr. Joy Smith"
        } ]
   } ]
}

 

JSONファイルから配列を削除

 

JSONDelete ('A'VAR, '/AddressBook[1]/Contact[1]')

 

AddressBook[1]からContact[1]を削除するには、オブジェクトパス'/AddressBook[1]/Contact[1]'を使用することができます。

その結果、AddressBook[1]のハイライト表示の部分が削除されます。

 

{"AddressBook": [{
       "Contact": [{
             "Record_ID": 0,
             "Name": "Mrs. Lee Smith",
              "City": "Tel Aviv"
       },
       {
           "Record_ID": 1,
           "Name": "Mr. Joy Smith"
        } ]
   } ]
}

 

以下の関数を実行すると、Contact Indexが正しくないため、エラー-4 を返します。

 

JSONDelete ('A'VAR, '/AddressBook[1]/Contact[0]')

 

以下の関数を実行すると、AddressBook[1] の配下の要素がすべて削除されます。

 

JSONDelete('A'VAR,'/AddressBook[1]')

注意事項：

オブジェクトのパスとして、複数のインスタンスを指定することはできません。
