JSONExist

JSONオブジェクトのチェック

JSONオブジェクト/配列がJSONソース変数に存在するかどうかをチェックします。

構文：

JSONExist (JSON ソース, パス)

パラメータ：

  • JSON ソース …… JSON 型項目の参照値です。

  • パス  …… パスの中の1つのオブジェクト/配列を一意に定義する文字列です。

戻り値：

論理値 …… JSONオブジェクト/配列がJSONのパスによって正常に位置決めされた場合はTrue、そうでない場合はFalse が返ります。

例：

JSONExist ('A'VAR, '/AddressBook[1]/Contact[1]/City')

 

'A'VAR は、JSON型のデータ項目です。以下の JSONデータが含まれています。

オブジェクトパス '/AddressBook[1]/Contact[1]/City' を使用して、与えられたJSONファイル内のCityを探すことができます。

Cityが存在している場合（Contact[1]）、この関数はTrueを返し、そうでなければ（Contact[2]） Falseを返します。

 

{"AddressBook": [{
            "Contact": [{
                      "Record_ID": 0,
                      "Name": "Mrs. Lee Smith",   
                      "City": "Tel Aviv"                  
               } ,

               {
                       "Record_ID": 1,
                        "Name": "Mr. Joy Smith"              
                } ]
      } ]
}

 

配列の存在をチェック

 

JSONExist('A'VAR,'/AddressBook[1]/Contact[1]')

 

オブジェクトパス '/AddressBook[1]/Contact[1]' を使用して、与えられたJSONファイルからContact[1]を探すことができます。Contact[1]が存在すれば、この関数はTrueを返し、そうでなければFalseを返します。

以下の場合は、True が返ります。

 

{"AddressBook": [{
      "Contact": [{
           "Record_ID": 0,
           "Name": "Mrs. Lee Smith",
           "City": "Tel Aviv"
        },
        {
           "Record_ID": 1,
           "Name": "Mr. Joy Smith"
         } ]
    } ]
}

注意事項：

オブジェクトのパスとして、複数のインスタンスを指定することはできません。
