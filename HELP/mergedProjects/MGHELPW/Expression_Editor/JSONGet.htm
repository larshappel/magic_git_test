JSONGet

JSONオブジェクトの取得

JSONソース項目から、指定されたパスに従ってJSONオブジェクト／配列の値を返します。

構文：

JSONGet (JSON ソース, パス,)

パラメータ：

  • JSON ソース …… JSON 型項目の参照値です。

  • パス  …… パスの中の1つのオブジェクトを一意に定義する文字列です。

戻り値：

JSONオブジェクト/配列の値

例：

JSONオブジェクトの値を取得する。

 

JSONGet('A'VAR,'/AddressBook[1]/Contact[1]/City')  

 

'A'VAR は JSON 型の変数です。以下の JSONデータが含まれています。

パス '/AddressBook[1]/Contact[1]/City' からJSONオブジェクトの値を取得すると、'Tel Aviv'が返されます。

 

{"AddressBook": [{
           "Contact": [{
                  "Record_ID": 0,
                  "Name": "Mrs. Lee Smith",
                  "City": "Tel Aviv"
              },
              {
                   "Record_ID": 1,
                   "Name": "Mr. Joy Smith"
             } ]
     }]

}

 

JSON配列の値を取得します。

 

JSONGet('A'VAR,'/AddressBook[1]/Contact[1]')

 

以下の配列値が返ります。ソートされた値が返ります。

 

{

 "City": "Tel Aviv",

 "Name": "Mrs. Lee Smith",

 "Record_ID": 0

}

注意事項：

オブジェクトのパスとして、複数のインスタンスを指定することはできません。
