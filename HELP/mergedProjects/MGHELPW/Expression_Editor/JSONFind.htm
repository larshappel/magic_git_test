JSONFind

JSONオブジェクトの検索

JSONソース項目からJSONオブジェクト/配列を検索します。

構文：

JSONFind (JSON ソース, オブジェクト・パス, 値 [, before/at])

パラメータ：

  • JSON ソース …… JSON 型項目の参照値です。

  • オブジェクトパス  …… パスの中の1つのオブジェクトを一意に定義する文字列です。

  • 値 …… オブジェクトを変更したいデータを含む値です。

  • begin at …… (オプション) 検索処理がオブジェクトパスのどこから開始するかを指定することができます。デフォルト値は、オブジェクトパス内の最初のJSONオブジェクトの出現位置から開始されます。

戻り値：

数値 …… 指定された値と等しい値を持つJSONオブジェクトのインデックスを返します。

JSONの解析処理が不完全であった場合、あるいは要求されたオブジェクト/配列が存在しない場合、 以下のエラーを返します。

  • -1 …… パスが見つかりません。

  • -4 …… パスに使用されているインデックスが無効です。

  • -5 …… JSONの解析でエラーが発生しました。

  • -6 …… 無効なパラメータです。

  • -7 …… 指定されたソース項目がJSON型ではありません。

  • -8 …… 指定されたJSON項目がNULLです。

  • -9 …… オブジェクトのパスがインデックスを持たない配列を参照しています。

  • -10 …… シングルインスタンスのパスは指定できません。

  • -11 …… JSONソース項に一致するオブジェクト/配列が見つかりません。

  • -12 …… インデックスまたは[]が単一のインスタンス（オブジェクト）で使用されている

例：

JSONFind ('A'VAR, '/AddressBook[1]/Contact', 'City', 'Tel Aviv')     //  "1" が返ります。

JSONFind ('A'VAR, '/AddressBook[1]/Contact', 'City', 'Tel Aviv', 2) // "3" が返ります。

 

'A'VAR は、JSON型のデータ項目です。以下の JSONデータが含まれています。

指定されたJSONファイルから、オブジェクトパス '/AddressBook[1]/Contact[1]/City' に値 'Tel Aviv' を指定すると、Cityを見つけることができます。

 

{"AddressBook": [{

      "Contact": [

         {"Record_ID": 0, "Name": "Mrs. Lee Smith", "City": "Tel Aviv" },

         {"Record_ID": 1, "Name": "Mr. Joy Smith"  },

         {"Record_ID": 2, "Name": "Mrs. Hope Swan", "City": "Tel Aviv" },

         {"Record_ID": 3, "Name": "Mr. Peter Franz","City": "Tel Aviv" }

     ] }

  }]

}

次の関数を実行すると、使用されているインスタンスパスが1つであるため、-10を返します。

 

JSONFind('A'VAR,'/AddressBook','CompanyName','Magic Software')

 

次の関数を実行すると、Monetary_value1 と一致するオブジェクトパス（キー）がないため、-11 を返します。

 

JSONFind('A'VAR,'/AddressBook/Contact','Monetary_value1',96.81)

 

次の関数を実行すると、Monetary_valueに一致する配列（value）が見つからないため、-11を返します。

 

JSONFind('A'VAR,'/AddressBook/Contact','Monetary_value',96.88)

注意事項：

オブジェクトのパスとして、複数のインスタンスを指定することはできません。
