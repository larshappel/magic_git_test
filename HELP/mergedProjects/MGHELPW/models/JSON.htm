JSON

JSON型のデータ項目は、データ ソース定義内の埋め込み JSON 構造を指定します。

JSONは、一つのデータ項目の中に階層構造を持ったオブジェクトまたは配列を格納することが可能です。このようなJSONの定義に対して、Magic xpaではJSON型項目を定義して対応します。

JSON型のデータは、内部では Unicode として格納されています。

JSON型の項目には以下の特性があります。

JSON 定義

この特性は、［データソース］リポジトリやコンポーネントからJSONデータソースを選択できるようにするものです。

 

この特性からズームすると、共有データソースの一覧が表示されます。共有データソース一覧からさらにズームすると、関連するすべてのプライベートデータソースが表示されます。

ここで他の共有データソースのプライベートデータソースを選択すると、そのプライベートデータソースが共有データソースに変換されます。

この共有データソースは、［データ］リポジトリで表示されます。

 

例えば、以下の状態を想定します。

  • "A"は共有データソース

  • "B" は"A" のプライベートデータソース

  • "C"は、別の共有データソース

このような場合、

  1. JSONテーブル"C"の［JSON 定義］特性から［データソース一覧］にズームします。

  2. 一覧で"A" を選択した状態で ［ズーム］ボタンをクリックすして［プライベートデータソース一覧］を表示します。(［ズーム］ボタンは、コンポーネントのJSONテーブルや、データソースの選択一覧から複数のデータソースが選択されている場合は無効です。)

  3. ここで "B"を選択して［選択］ボタンをクリックすると、確認ダイアログが表示された後、"B"は共有テーブルに変換されます。

この特性が空白かつ［カラム名］をが設定された状態の場合、カラム名からズームすると、プライベートデータソースが作成され、作成されたJSONデータソースを修正することができます。

プライベートデータソースは、［データ］リポジトリ上には表示されませんが、、［ナビゲータ］の［データ］に表示される登録数に反映されています。

インスタンス

この特性は、JSONが持つインスタンス数を指定します。可能な値は2つあります。

  • シングル

  • マルチ

「シングル」が選択された場合、{...} で囲まれたオブジェクトのデータとして格納されます。

例：

"EmpName": {

        "firstName": "John",

        "lastName": "Williams"

      },

「マルチ」が選択された場合、[{...}]で囲まれた配列のデータとして格納されます。

例：

 "EmpContact": [

        {

          "MobNo": 1,

          "PhoneNo": 09012345678

        },

        {

          "MobNo": 2,

          "PhoneNo": 08012345678

        }

      ],

 

JSON型項目を定義するには、2つの方法があります。

  • ［JSON定義］特性から、他のJSONデータソースの番号を指定します。…… 指定したデータソースのことを Magicでは共有データソースと呼びます。

  • JSON型項目の［名前］からズームしてデータソースの定義を行います。このデータソースは他のテーブルから参照できないので、 Magicではプライベートデータソースと呼びます。

プライベートデータソースで作成した定義を他のJSONテーブルで利用するために、次のように共有データソースに変更することが可能です。

    1. 新しく定義したJSON型項目の［JSON定義］プロパティでズームします。

    2. JSONデータソースの一覧が表示されるので、すでに定義済みのプライベートデータソースのJSONデータソースにカーソルを置いて、左下のズームボタンを押下します。

    3. プライベートデータソースの中で利用するデータソースを選択します。

    4. Escキーを押下して戻ると、確認のダイアログが表示されるので[OK]ボタンを押下します。

    5. ［JSON定義］特性に番号が設定され、選択したデータソースが［データ］リポジトリの最終行に追加されます。
